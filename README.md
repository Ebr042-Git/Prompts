# Prompts

A curated collection of reusable, high-quality prompts I use for learning, testing my knowledge, and working with AI assistants (Claude, ChatGPT, Copilot, etc.).

## 📂 Structure

| Folder | Purpose |
|---|---|
| `learning-plans/` | Prompts that generate focused, time-boxed learning plans (80/20 principle) for any topic |
| `self-testing/` | Prompts that quiz and grade understanding after studying a topic |
| `youtube-channels/` | Per-channel voice files and Claude rules for the YouTube agent skills |

## 💡 Why This Repo Exists

Good prompting is a skill on its own. Instead of rewriting the same instructions every time I want to learn something new or test myself, I keep refined, reusable templates here — versioned and improved over time like code.

## 🛠️ How to Use

1. Pick the relevant `.md` file for your goal (learning a topic vs. testing yourself)
2. Copy the prompt template
3. Replace the placeholder (e.g., `[topic]`) with your actual subject
4. Paste into your AI assistant of choice

---
*This repo grows as I refine my prompting approach — treat it like a live playbook, not a finished product.*
